# Нефтекод

Локальное приложение поддержки технологических решений: модельные рецептуры дизельного топлива, исторический прогноз серы и объяснимые проверки ограничений.

[Скачать Windows-версию](https://github.com/bug00n/HackathonPetrolCode/releases/latest/download/Neftekod-Windows-x64.zip) · [Все файлы релиза](https://github.com/bug00n/HackathonPetrolCode/releases/latest) · [Сценарий защиты](docs/DEMO_SCRIPT.md)

## Запуск за три шага

1. Скачайте **Neftekod-Windows-x64.zip** по ссылке выше и распакуйте **весь архив**.
2. Откройте **Neftekod.exe** (Windows x64). Дождитесь готового результата на экране «Обзор».
3. Нажмите **«Смесь»**, чтобы увидеть рецепт и проверки. Кнопка **«Настроить смесь»** позволяет изменить входы и пересчитать вариант.

Приложение работает локально: Python, Docker, обучение моделей и интернет после скачивания не нужны. Не запускайте EXE прямо внутри ZIP и не переносите его отдельно от `_internal`, `config`, `data` и `artifacts`.

**Code → Download ZIP скачивает исходники, а не готовое приложение.** Для запуска без настройки используйте Releases. Закрытый репозиторий и его релизы доступны только пользователям с выданным доступом; для показа на другом компьютере можно передать скачанный полный архив.

## Что показать первым

В приложении на «Обзоре» уже рассчитан сценарий **«Повышенная сера»**. Откройте **«Смесь»**: верхняя модельная оценка серы меняется с 14,058 до 9,306 мг/кг при пределе 10 мг/кг. Нажмите **«Настроить смесь»**, чтобы изменить долю, сохранить важное поле отметкой «Не менять» и сравнить допустимые варианты.

| Раздел | Что доступно |
| --- | --- |
| Обзор и Смесь | Шесть сценариев и кнопка «Настроить смесь»: автоподбор рецептуры, свойства компонентов, запасы и присадка |
| АВТ и Гидроочистка | Исторические сигналы, единицы, источники и свежесть |
| История/ML | График прогноза и верхней оценки, выбор периода, прогресс, отмена и экспорт |

## Границы результата

Это **демонстрационный прототип, не система промышленного управления**. Реальные уставки отключены (`supports_actions=false`). Рецептуры и стоимостные показатели модельные; Hybrid проверяет только серу, v2 работает в shadow-режиме.

На отложенных данных ПАК 2026 года: **31 819** сопоставимых целей, MAE **0,6842 мг/кг**, равен persistence baseline. Превосходство модели и промышленная экономия не заявляются. [Подробности оценки](docs/evidence/forecast-test/metrics.json).

## Если не запускается

- Проверьте полную распаковку и наличие `_internal`; используйте папку с правом записи.
- Сборка предназначена для **Windows x64**; EXE не подписан цифровой подписью. Соблюдайте политику компьютера, не отключайте защиту ради запуска.
- При программной ошибке проверьте `startup-error.log` рядом с EXE.
- Сверить архив можно по SHA-256 на странице релиза; внутри есть `SHA256SUMS.txt` для отдельных файлов.

Полная инструкция запуска приведена выше; сообщения ошибок сохраняются рядом с EXE.

## Для разработчика

Редактор синтетической смеси предлагает допустимые доли после изменения поля, сохраняет поля «Не менять» и показывает варианты «ближе», «дешевле» и «меньше присадки». Для проверки откройте «Обзор» → «Настроить смесь», измените долю компонента и нажмите Enter или «Подобрать смесь». «Отменить подбор» возвращает введённые значения; переключатель «Подбирать после изменения» включает и выключает автоматический подбор. Кнопка «Подобрать смесь» работает и при выключенном переключателе.

В `main` находится сдаваемая версия без дневников разработки. Планы этапов, старые ревью и журнал проблем сохранены в [ветке dev](https://github.com/bug00n/HackathonPetrolCode/tree/dev); конкретная поставка закреплена тегом релиза. В Git хранятся исходники, конфигурации, тесты и технические материалы. EXE, презентация, Word-документ, подготовленные данные и модели поставляются через Releases. Уведомления сторонних компонентов сохранены в [third_party/licenses](third_party/licenses).

[Запуск исходников, тесты и сборка](docs/DEVELOPMENT.md) · [Архитектура и контракты](DESIGN.md) · [Уточнения организаторов](docs/technical/QA_CLARIFICATIONS.md)

Быстрый модельный запуск после получения исходников, из корня проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m source.main validate-stage0
.\.venv\Scripts\python.exe -m source.ui --page overview
```

Без ресурсов релиза в исходном checkout доступны модельные сценарии. Для истории перенесите закреплённые `data/processed` и `artifacts/models` из той же поставки, как описано в руководстве разработчика. Переобучение для демонстрации не требуется.
