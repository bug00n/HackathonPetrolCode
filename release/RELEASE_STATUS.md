# Статус финального комплекта

Финализация подготовлена 22.09.2026 поверх dev 88e317e. Первый локальный архив был собран из незакоммиченного дерева. Для публикуемых выпусков точный commit, дату и признак dirty всегда смотрите в `RELEASE_MANIFEST.json` самого ZIP; контрольные суммы — в `SHA256SUMS.txt`. GitHub Release закрепляет конкретный тег, а не изменяемое состояние ветки.

## Что исправлено после повторного ревью

- AP-004, AP-010: очередь передачи результатов в главный Tk-поток, защита закрытых экранов, снимок по источникам вместо сериализации всей истории, ускоренный поиск опубликованных анализов.
- AP-009, AP-018: progress, кооперативная отмена на границе точек, явный частичный результат, экспорт показанного интервала. На одну задачу данные и модель загружаются один раз.
- AP-005: validation сохранённого artifact явно обозначается in_sample_diagnostic; независимый результат формируется на test.
- AP-007: добавлен blend_tradeoff, где снижение риска требует повышения стоимостного прокси.
- AP-008: повторно оценён закреплённый artifact на 31 819 отложенных точках ПАК 2026 года, отчёт и residuals включены. Превосходства над baseline нет и не заявляется.
- AP-011, AP-016: закреплённая пара не подменяется при отсутствии файлов; исторические формы разделяют dataset и время.
- AP-012, AP-014, AP-020: единый комплект с Windows-runtime, исходниками, полезными MD, моделями, данными и актуальными материалами жюри.

## Границы

Исследовательские ограничения не закрываются переименованием: supports_actions=false, Hybrid sulfur-only, надежность и экономика модельные. Тест 2026 — оценка прогнозирования, не доказательство эффекта невыполненных действий. Расчёт без сети возможен в готовой Windows x64 поставке; исходный запуск требует отдельного Python-окружения.
