# НЕФТЕКОД — начните здесь

Готовый Windows-архив: [GitHub Releases](https://github.com/bug00n/HackathonPetrolCode/releases/latest). «Code → Download ZIP» содержит только исходники. Для закрытого репозитория нужен доступ; после скачивания приложение работает без сети.

## Запуск: Windows x64

1. Распакуйте **весь ZIP** в обычную папку, доступную для записи, например `D:\Нефтекод`.
2. Запустите `Neftekod.exe`. Не переносите EXE отдельно от `_internal`, `config`, `data` и `artifacts`.
3. На «Обзоре» выберите сценарий и выполните расчёт, затем откройте «Смесь». Для первого показа подходят «Повышенная сера» и «Риск и стоимость».

Python, установка библиотек, обучение и интернет для этой сборки не нужны. Исторический расчёт занимает время: экран показывает прогресс, интервал можно отменить с сохранением завершённых точек. EXE не подписан цифровой подписью. Соблюдайте политику безопасности компьютера; не отключайте защиту ради запуска. При ошибке запуска проверьте `startup-error.log` рядом с EXE.

## Что открыть для защиты

- `release/jury/Neftekod_Presentation.pptx` — редактируемая презентация.
- `release/jury/Neftekod_Jury.docx` — технический документ для жюри.
- `release/DEMO_SCRIPT.md` — пятиминутный показ и ответы на вопросы.
- `release/JURY_REPORT.md` — исходный текст технического документа.
- `release/RELEASE_STATUS.md` — исправления и проверки.
- `DESIGN.md` — архитектура и контракты; `actual problems.md` — история проблем.
- `release/evidence/` — расчёты и независимая test-оценка.

Stage-планы и старые ревью сохраняют историю разработки. Текущий статус поставки определяется `release/RELEASE_STATUS.md`.

## Границы продукта

Локальный прототип поддержки решений. Модельные рецептуры — явно заданные сценарии, история — прогноз без управления, hybrid — условное смешение по сере, v2 — исследовательские предупреждения. Реальные уставки не изменяются: `supports_actions=false`.

## Исходники (для разработчика)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m source.main validate-stage0
.\.venv\Scripts\python.exe -m source.ui --page overview
```

Установка библиотек требует сети или заранее подготовленного wheelhouse. Данные и совместимые модели закреплены в `config/release_manifest.json`.

## Целостность поставки

`RELEASE_MANIFEST.json` фиксирует исходный commit и незакоммиченные изменения. `SHA256SUMS.txt` содержит суммы файлов на момент сборки; пользовательские журналы после запуска могут изменяться. `reports/portable-smoke.json` — проверка EXE, `reports/release-acceptance/` — приёмочные сценарии.
