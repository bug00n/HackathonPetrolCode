# Сценарий защиты Нефтекода

## До выступления

Полностью распаковать ZIP. Открыть `Neftekod.exe`. Не запускать прямо внутри архива и не переносить exe отдельно от `_internal`, config, data и artifacts. Открыть презентацию, скачанную из GitHub Releases или взятую из полного ZIP. Проверить, что экран обзора показывает рассчитанный модельный сценарий. При показе с проектора уменьшать окно можно до 1000×680; нижние блоки доступны прокруткой.

## Показ за пять минут

1. **Назначение, 30 секунд.** «Это локальная система поддержки решения. Реальные измерения и модельные сценарии разделены. Промышленное управление отключено».
2. **Повышенная сера, 60 секунд.** На обзоре выбрать сценарий и нажать «Рассчитать». Открыть «Смесь». Показать 14,058 и 9,306 мг/кг, состав 89,1/9,9/1%, успешные модельные проверки T95/CN. Объяснить, что дешёвый недопустимый вариант отфильтрован.
3. **Отказ и конфликт, 60 секунд.** Выбрать недостающие данные: результата управления нет. Затем «Риск и стоимость»: индекс риска 0,80 → 0,73 при росте стоимости 1,99 → 2,0395. Это модельные прокси, не производственная экономия.
4. **История, 90 секунд.** Время начала 2025-06-01T12:00:00+03:00, конец 2025-06-01T13:00:00+03:00. Нажать «Рассчитать интервал». Пока он считается, объяснить время доступности ЛИМС. Показать прогресс, две точки, верхнюю границу и отсутствие управляющих действий. Экспортировать результат. Длинный интервал можно отменить; частичный результат подписан.
5. **Проверяемость, 60 секунд.** Открыть журнал. Показать выбранный сценарий и полный след. Завершить фактической ML-оценкой на 31 819 точках: MAE 0,6842 мг/кг, равен baseline. Основной результат проекта — согласованный безопасный цикл, а не заявленное превосходство этого baseline.

## Дополнительные вопросы

- **Почему без LLM?** Численные агенты и явные контракты решают обязательный цикл локально и воспроизводимо.
- **Что делает Hybrid?** Подставляет прогноз серы A в условную смесь. Остальные свойства здесь не подтверждены.
- **Почему abstain при наличии числа?** Прогноз качества доступен, но проверенной модели последствий реального действия нет.
- **Можно ли изменять период в UI?** Да: «История/ML» → «Момент данных» (начало) и «Конец исторического интервала» → «Рассчитать интервал». Даты вводятся с часовым поясом, например `2025-06-01T12:00:00+03:00`. В UI шаг фиксирован: 60 минут. Другой шаг задаётся только в CLI через `--step-minutes`.
- **Откуда уверенность?** Верхние оценки эмпирические или сценарные согласно режиму. Промышленную гарантию они не дают.
- **Что ещё исследуется?** Причинные эффекты P8/F19, надёжность, межустановочные задержки и лабораторная коррекция. В штатной поставке реальные действия выключены.

## Если запуск не удался

Не удалять `_internal`. Повторно распаковать весь архив в пользовательскую папку. Сверить SHA256SUMS. При программной ошибке сохранить `startup-error.log`. При ограничениях запуска со стороны Windows следовать политике компьютера, не отключать антивирус. Для технического проверяющего сохранён исходный маршрут Python в README.
